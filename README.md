# 4gChat — AI Chatbot CLI

4gChat is a small command-line tool that asks an LLM (OpenAI Responses API)
to generate a shell command from a natural-language prompt, and — if the AI
returns a valid command — executes it locally.


Configuration
-------------

The app looks for your OpenAI API key in a JSON file at `~/.4gchatConfig.json`.
Create that file with the following format (replace with your real key):

```json
{
	"OPENAI_API_KEY": "your-key-here",
	"OS": "linux"
}
```

Usage
-----

Run the CLI with a prompt describing the command you want. From the project
root:

```bash
npm install -g
4gchat "list all files in this directory"
```

If the AI returns a command the CLI will print and execute it. Example output:

```
Executing command: touch nums.txt

# (any stdout from the command)
```

Development
-----------

- Node.js (14+ recommended)
- Install deps: `npm install`

You can make the CLI executable by adding a small npm script or by installing
it globally (npm link) if desired.

Contact / notes
---------------

This is a tiny project intended as a helper to prototype AI-assisted shell
automation. Be careful running commands generated by models.
